## 🎮 How to Play

1. **Press `Play`** to start the Big Bang.
2. **Adjust sliders** before starting:
   - `Gravity (G)`: Higher → faster clustering
   - `Dark Energy (Λ)`: Higher → faster expansion
   - `Galaxies` / `Planets`: Max count to generate
   - `Speed`: Time acceleration (0.1x – 10x)
3. **Drag** to pan, **scroll** to zoom.
4. **Use the timeline** to jump to any era (going backward resets).
5. Watch for **green planets** – **life has emerged!**

> **Pro Tip**: For life, use `G ≈ 0.5–1.5`, `Λ < 2.0`, and wait past **9.7 billion years**.

## 🧪 Physics Behind It

Simplified models of real cosmology:

- **Hubble's Law**: `v = H × d`
- **Newtonian Gravity**: `F = G × m₁ × m₂ / r²`
- **CMB Cooling**: `T ∝ 1/a` (scale factor)
- **Stellar Nucleosynthesis**: Sequential element creation
- **Dark Matter Halos**: Invisible scaffolding for galaxies
